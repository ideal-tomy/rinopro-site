# AXEON 半内製化「支援の進め方」階段状レイアウト修正

## 依頼

半内製化ページの「支援の進め方」だけを修正してください。

添付1枚目が現在の表示、添付2枚目が形状の参考です。4枚のカードを少しずつ上にずらすだけでなく、カード下端の段差に沿って階段状の線を描き、左から右へ段階的に上がっていく表現にしてください。

また、現在タイトルの上に独立して表示している数字を、タイトルの左に移動してください。数字とタイトルの間で改行して、数字だけが1行を占める表示はやめてください。

この指示は、以前の半内製化指示書にある「支援の進め方」の配置指定を更新するものです。他のセクションは変更しません。

## 1. 維持する内容

- H2「支援の進め方」と、その青い下線
- 導入文「実際の業務を一緒に進めながら、社内で対応できる範囲を広げます。」
- 現在の4段階と、それぞれの説明文
- 1〜3の淡青、4の濃紺という配色関係
- 最後の「必要に応じて、開発会社との打ち合わせにも同席し、要件や進め方の確認を支援します。」という補足
- ページ内リンク、ヒーロー、確認事項、対比、開発タブ、CTA

参考画像から取り入れるのは、段階が上がる配置と階段状の基準線です。赤い配色、人物イラスト、旗、STEPラベル、美容サービスの文言、3段階の項目数は持ち込みません。AXEONの4段階を維持します。

## 2. PC：カードと階段線を一体にする

### カードの配置

- 4枚を左から右へ、同じ幅で配置します。
- カードは同じ高さを基本とし、上端・下端の両方が右へ進むにつれて上がる形にします。
- 1段あたりの高さ差は24〜32pxを初期目安にします。現在の約12〜16pxの差より、階段として認識できる差にします。
- カード間隔は16〜20pxを目安にします。
- 各カードの内側余白・タイトル位置・本文位置を統一します。
- 最も長い内容に合わせた共通高さを使い、本文を切り取る固定高さにはしません。
- 不要な大きい空白をカード内に作らないでください。

### 階段状の線

- カード下端の少し下に、ブランドブルーの階段線を追加します。
- 線は1枚目の下で水平に進み、カード間で垂直に上がり、2枚目の下で再び水平に進む形にします。同じ関係を4枚目まで続けます。
- 水平部分は各カードの下端に沿い、垂直部分はカード間の余白内に配置します。
- 各カード下端と線の間は約8〜12pxを目安にそろえます。
- 線の太さは2px程度。濃紺やブランドブルーを使います。
- 線をカードの本文やタイトルに重ねないでください。
- カード上端の既存の青い線と、下の階段線が過剰に競合する場合は、上端の線を弱めるか削除し、階段線を優先します。
- 参考画像のように階段の下を塗る場合も、ごく淡い青の浅い領域にとどめます。大きな装飾面や高い台座を作らないでください。まず階段線だけで成立させます。

### 実装上の注意

- カードの段差と階段線は、同じCSS変数・レイアウト値から算出してください。別々の固定座標で目視調整して、画面幅によってずれる実装は避けます。
- 例として、4枚のカードのオフセットを `3 × 段差 / 2 × 段差 / 1 × 段差 / 0` とするGrid配置が使えます。
- 上記なら、上に飛び出すtranslateより、上余白・配置行等で段差を作ると、必要なレイアウト高さを確保しやすくなります。既存実装の方式を使う場合も、補足文と重ならないよう高さを確保してください。
- 階段線はCSSの疑似要素、SVGなどで描けます。カード本文はHTMLで保持します。
- 装飾SVGには `aria-hidden="true"` を付け、クリックやフォーカスを妨げないようにします。
- `overflow: hidden` でカードや線の端を切らないでください。
- 下の補足文は、最も低い1枚目と階段線の下から24〜32px程度あけて配置します。

## 3. 数字はタイトルの左に配置

### 目指す表示

数字「1」とタイトル「課題と担当を整理する」を、同じ見出し行の中で横に並べます。他の3枚も同じルールにします。

- 数字のための独立した上段を削除します。
- 数字とタイトルの間に `<br>` やブロック要素による強制改行を入れません。
- 番号は1〜4のみ。STEP、英語ラベル、大きい旗、二重の番号表示は追加しません。
- 見出しの構造は、数字とタイトルを1つのH3内に入れるか、同じ見出し行の中にまとめます。
- 見出し行は横向きFlex等で実装し、数字は `flex-shrink: 0`、タイトル側は `min-width: 0`。
- 数字は20px程度・太字、タイトルは既存サイズを基本に20〜22px程度。数字とタイトルの間は8〜12px。
- 番号とタイトルの最初の行をそろえます。タイトルが2行になる場合、番号を2行全体の中央に置かないでください。
- 1〜3では番号を青、4では番号も白にし、十分なコントラストを確保します。
- 数字のために大きな円や箱を作る必要はありません。

### タイトルの折り返し

「数字とタイトルを同じ行にする」とは、数字だけを別行にしないという意味です。長いタイトルをすべて `white-space: nowrap` にしてはみ出させる指示ではありません。

- 収まるタイトルは1行で表示します。
- 長いタイトルは意味のまとまりで2行にできます。
- 現在の「社内で改善できる範囲を広／げる」のような折り返しは避けます。
- 最終項目を2行にする場合は、「社内で改善できる」「範囲を広げる」のまとまりで折り返す方法が使えます。
- まずカード幅・内側余白・文字サイズを調整します。必要な場合だけ、短い意味のまとまりをspanにし、その内部の折り返しを制御してください。
- 本文は自然に折り返します。大量の強制改行や文字単位のspanを追加しません。
- タイトルを小さくして数字と無理に1行に収めたり、説明文を削ったりしないでください。

## 4. SP・狭い画面

- 4列で本文が読みにくくなる幅では、現在のSP用縦配置を維持・調整します。
- SPで横4列の階段図を縮小して表示しません。
- PC用の段差と横向き階段線は解除し、カードを通常の縦並びにします。
- 必要なら細い縦の接続線で順序を示せますが、今回必須ではありません。
- **SPでも数字はタイトル左に置き、数字だけの独立行を作りません。**
- カード本文は16px以上を基本にし、内容に応じて高さが増えるようにします。
- 文字拡大時に見出しや本文が切れないようにします。

既存プロジェクトで必要なビルド・型チェック等を実施し、実ブラウザで確認してください。

- [ ] 下端に沿った階段線があり、カードと同じ段差になっている
- [ ] 階段線の上がる位置が、カード間の余白にある
- [ ] カード下端と階段線の距離がそろっている
- [ ] 数字がタイトル左にあり、独立した1行になっていない
- [ ] 長いタイトルが末尾1文字だけで折り返されていない
- [ ] 最終カードの白文字が読みやすい
- [ ] カード内に大きな無意味な空白がない
- [ ] カード・階段線・補足文が重ならない
- [ ] SPでは段差を解除し、数字とタイトルは横並びになっている
- [ ] 本文を省略したり、切り取ったりしていない
- [ ] 他のセクションを変更していない

最後に、変更ファイル、確認した幅、ビルド結果、未確認事項を簡潔に報告してください。PCで階段線まで見えるセクション全体と、SPで数字の位置が分かるスクリーンショットを提示してください。
