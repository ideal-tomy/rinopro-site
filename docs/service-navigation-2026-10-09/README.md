# ご支援内容の導線改善（2026-10-09）

## 確認した問題と対応

- ハンバーガーメニューでは詳細ページの存在が分からなかったため、「ご支援内容」の下に「コンサルティング」「半内製化」を常時表示。閲覧中のページを強調し、リンク選択で閉じる動作と閉じた後のフォーカスも確認。
- 詳細ページへ直接訪問した場合も移動先が分かるよう、両ページの冒頭と末尾に「ご支援内容へ戻る」と他方の詳細ページへのリンクを追加。
- 既存のページ内リンクをヘッダー直下に追従させ、閲覧中のセクションを表示。スマホの横スクロール内でも現在の項目が隠れないよう調整。
- 長い開発工程を読み進めてもタブを操作できるよう、開発工程のタブとPC相談例のタブをページ内リンクの直下に追従。切り替え時は選択した説明の冒頭を操作部分の下に表示し、キーボードフォーカスは維持。
- スマホの相談例には従来のスワイプとボタンに加え、左右矢印・Home・Endキー操作を追加。

既存セクションの見出し、本文、画像、配色、工程レイアウトは維持。追加したのは移動に必要なナビゲーションで、掲載本文と全タブの本文は改修前後のブラウザー取得結果で一致（[比較結果](content-comparison.json)）。

## 検証

- 自動ブラウザー検証：[実行スクリプト](../../scripts/verify-service-navigation.cjs)、[結果](verification.json)。
- 幅320 / 390 / 768 / 1024 / 1440px。390pxでは高さ614pxの短い画面を使用。
- メニューの階層・現在地・開閉・Escape・フォーカス復帰・実際のページ移動。
- ページ内リンクの移動位置と現在地、全タブの切り替え、深い位置から説明冒頭への復帰、キーボード操作、本文の横はみ出し、両方向の詳細ページ移動、一覧への戻り。
- ESLint、TypeScriptを含む本番ビルドは成功。上記ブラウザー検証は本番プレビュー（http://127.0.0.1:3109）で全幅成功、ブラウザー実行エラーなし。
- 通常アニメーションでの深い位置からのタブ切り替えと、現在のページ内リンクの可視性も成功（[結果](normal-motion.json)）。
- 実機のiOS Safari / Android Chromeは未確認。
