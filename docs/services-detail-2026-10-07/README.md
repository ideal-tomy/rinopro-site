# 詳細ページの404復旧

2026-10-07確認。

同じリポジトリの3000番開発サーバーで `/services/consulting` と `/services/insourcing-enablement` がHTTP 404を返していた。一方、3103番のビルド済みプレビューは両方HTTP 200。ページファイル、半内製化のコンテンツ、カードのリンク先はいずれも存在しており、変更や削除はなかった。

3000番の開発サーバーを再起動すると両方HTTP 200になった。開発サーバーのルート読み込み状態による不具合であり、再起動で復旧した。内部状態が不整合になった直接の契機までは確定していない。ソースコードの変更は不要だった。

Windows Chromeのスマホ390px表示で `/services` から実際にボタンを押し、URLが遷移するまで待って、各ページのh1が「コンサルティング」「半内製化」であることを確認した。

- [半内製化画面](enablement.png)
