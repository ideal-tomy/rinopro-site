# 建設デモ：ブランドに応じた問い合わせ先の切り替え

現在、以下の問題が発生しています。

- 建設デモを `?brand=axeon` で開いている。
- 画面下部の「相談する」を押すと、IDEALの問い合わせページへ移動する。

ロゴだけでなく、問い合わせ先などの遷移先も切り替えてください。
既存のブランド導線修正PLANに含まれる不具合として対応してください。

## 必須仕様

解決済みのブランドから、以下を一括して決定します。

- 表示ロゴ・ブランド名
- 公式サイトへのリンク
- 問い合わせ先
- 見積もりURLのbrand
- サイトへ戻るリンク

AXEONで開始した場合：
AXEONの表示・問い合わせ・見積もり・戻り先に統一する。

IDEALで開始した場合：
IDEALの表示・問い合わせ・見積もり・戻り先に統一する。

URLの有効なbrandを優先し、既存PLANの既定値・互換仕様を維持する。
共通のCONTACT_URLや環境変数によって、AXEON指定がIDEALへ上書きされないようにする。

## 修正対象

ハブの「相談する」だけでなく、写真・報告・現場オペ・完了画面・ヘッダー・フッターにある、実際の外部リンクを確認する。

各画面へ移動してもbrandを維持する。
既存のfromなど、画面連携用パラメータは壊さない。

問い合わせ先はブランド別の固定設定から選ぶ。
AXEONの正規問い合わせURLは、サイト設定と公開ページで確認する。
IDEAL向けの問い合わせパラメータを、AXEONへ無条件にコピーしない。

## 検証

両ブランドで、以下を確認する。

1. 入口URLを開く。
2. 写真→報告→現場オペ→ハブへ移動する。
3. 「相談する」の実際のhrefを確認する。
4. クリックして、対応ブランドの問い合わせ画面へ到達する。
5. 見積もりとサイトへ戻るリンクも確認する。
6. 再読み込み・別タブでもブランドが変わらないことを確認する。

ロゴが合っているだけで完了にしない。
表示ブランド・実際のリンク先・クリック後の到達先を確認する。

すでに実装済みの場合は、修正したブランチ・コミットと
公開デプロイの対応を確認し、未反映なのかを切り分ける。

原因、変更ファイル、両ブランドの遷移先一覧、
公開環境での確認結果または未確認事項を報告してください。
