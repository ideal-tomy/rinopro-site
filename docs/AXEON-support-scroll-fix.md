# AXEON：掲載内容の整理・横スライド・スクロール表示の修正

## 対象と目的

リポジトリ：https://github.com/ideal-tomy/rinopro-site

「支援を始める前に」セクションがあるページと、今回の不具合に関係する表示処理を対象にしてください。現在のコードから対象URL・部品を特定し、報告してから修正を進めます。以前の /about という対象を、そのまま引き継がないでください。

ユーザーの作業中の変更を上書きせず、以下の内容整理と表示不具合の修正を行ってください。

## 1. 掲載内容の整理

### 「支援の進め方」など

「支援の進め方」の独立セクションは削除する方針です。
まず実際の見出しと構成を確認し、削除するセクションを明示してください。

「など」は、似た意味のセクションをすべて削除する指示ではありません。
同じ進め方を繰り返すセクションがあれば削除候補として報告し、特定されていない別セクションを勝手に削除しないでください。

該当セクションを削除した場合：
- セクション間の余白を整える。
- ページ内リンクや目次に存在しない移動先を残さない。
- 後続セクションの表示判定を壊さない。
- 必要な問い合わせ導線は維持する。

### 月額・更新周期の説明

対象ページから「月額支援」「月額の伴走」「3か月ごとの更新」等の説明を削除してください。
同じ内容がカード表面・裏面・補足に重複している場合も整理します。

注意：
- 契約周期に関する説明が対象です。
- 「開発期間1〜3か月」など、別の意味の期間まで削除しない。
- サイト全体の文章を検索置換して消さない。
- 削除後に不自然になる接続部分だけを最小限調整する。
- その他の文章、画像、リンク、カードの内容は維持する。

## 2. 「支援を始める前に」の縦ずれを直す

### ユーザーが確認した症状

- 特定のカードをタップした後は、横スライド時に上下へ動かない。
- ページをスクロールしてセクションを表示させ、そのままカードを横へ動かすと、カードが上下に動いて表示が崩れる。

原因はまだ断定しません。実際に再現してから修正してください。

### 再現手順

1. ページを再読み込みする。
2. 上から縦スクロールして該当セクションへ入る。
3. 表示演出の途中で、カードを横スワイプする。
4. 演出が完了した後にも、横スワイプする。
5. カードをタップしてから、同じ操作をする。
6. 次・前のカードへ移動し、縦スクロールで離れて戻る。
7. 操作経路によって表示状態が変わるか比較する。

### 調査箇所

以下は原因候補です。該当していることを確認してから直してください。

- スクロール表示と横スライドが同じ要素の transform を変更している。
- 親と子に重複した縦移動アニメーションがある。
- 横スライドで表示判定が変わり、初期状態へ戻る。
- タップ・スワイプで要素が再マウントされる。
- active / hover / drag の指定が縦位置を変えている。
- 横スクロール領域が縦方向にも動いている。
- カード・画像の高さや読み込み状態が操作途中で変わる。
- 反転カードがある場合、表裏の高さや配置が外側の高さに影響している。

### 修正後の条件

- セクションの表示演出が完了した後、横スライドだけでカードの縦位置や領域の高さが変わらない。
- 演出途中の操作でも、表示位置が破綻しない。
- タップ済み・未タップで安定性が変わらない。
- 意図的なカードの反転機能やリンク操作は維持する。
- 画像の表示領域を読み込み前から確保する。
- 根拠なく巨大な固定高さを設定して解決しない。
- 横スライド上から始めた縦スワイプでも、ページを縦スクロールできる。
- touch-action や preventDefault でページの縦スクロールを一律禁止しない。
- ページ全体の overflow を隠して不具合をごまかさない。

## 3. スクロール表示をセクション単位に整理する

### 現在の症状

セクションがふわっと表示された後、その中のテキストが別のタイミングで表示される。
親子のタイミング・位置のずれが大きく、ガタついた表示になっている。

### 今回の表示方針

対象ページでは、基本的に「セクション単位で一度だけ表示」にしてください。

- セクションと、その見出し・本文を一緒に表示する。
- 同じセクションの子テキストに別のスクロール表示・長い遅延を重ねない。
- 表示後、少しスクロールしただけで非表示や初期位置へ戻さない。
- 横スライドやタップで表示演出を再実行しない。
- opacity を主体にし、縦移動を使う場合は小さな量にする。
- 縦移動は8〜12px程度、表示時間は0.5〜0.7秒程度を調整の出発点にする。
- height / margin / padding のアニメーションで周囲のレイアウトを動かさない。
- 表示演出の外側ラッパーと、スライド・反転を担当する要素を分けるなど、transform の競合を避ける。
- 独立したデモ再生・反転操作まで削除しない。
- 動きを減らす設定では、アニメーションなしで内容を表示する。
- 表示判定やJavaScriptの問題で、内容が透明のまま残らないようにする。

共通アニメーション部品を変更する場合は利用元を確認してください。
まず対象ページへ修正を限定し、他ページへ不用意に波及させないでください。
