## 今回の変更（文言変更なし）

| 箇所 | 変更 |

追記（2026-10-18）: 支援の内容・進め方・成果物のリード（2文・約47字）は、読み幅上限 `ax-pattern-prose` の `max-width: 42rem`（約42字）を5字ほど超えて「場合／もあります。」「ことも／できます。」と切れていた → PC（md 以上）のみ 1文1行＋文中は句単位に。SP は従来どおり自然折り返し（ページ内の `PcLine`）。

残課題: 支援の内容・進め方の項目本文（「使っ／ている」「決／めます。」など）は共通パターン `AxDecisionComparison` / `AxProcessFlow` が文字列のみ受け付けるため自然折り返しのまま。
