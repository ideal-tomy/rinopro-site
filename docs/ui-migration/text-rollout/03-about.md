## 今回の変更（文言変更なし）

| 箇所 | 変更 |
|------|------|
| 代表 | 原稿をトップの `ceo.message` と共有（二重管理を解消）。強調・引用を `AxRichParagraph` で同じ表示に |
| 代表 | PC で本文 1 行約 58 字 → `max-width: 42rem`（約 40 字）。SP 行間 1.5 → 1.8 |
| Hero リード | 1 文 1 行（PC）は維持し、文中は読点で折り返す（SP「必要な／対応」を解消） |
| お問い合わせ | 本文を句単位に（SP「こ／と」の分断を解消）。PC は `36em` で 2 行、行間 1.5 → 本文ロール |
| 大切にしていること | 本文の行間 1.5 → 本文ロール |
| module | `.heroBody span` → `.heroBody > span`（句の span まで block になるのを防ぐ） |

## 確認

| 幅 | 結果 |
|----|------|
| 390 | Hero・CTA が句単位。代表は「全文を読む」展開後も強調・引用が表示される |
| 1280 | 代表本文の行長、CTA 2 行 |

残課題: 「大切にしていること」は 3 列が狭く本文の行末が揃いにくい（本文扱いのため自然折り返しのまま）。
