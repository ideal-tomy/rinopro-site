# 3. AXEONを設立した理由

## 見出し

AXEONを設立した理由

## 本文

前職で大企業や政府機関の支援に携わるなかで、業務改善やシステム導入を必要としていても、規模や費用の面から外部の専門支援を利用しにくい企業があると感じました。

また、計画や試作まで進んでも、実際の業務で使うシステムの開発や運用までつながらないことがあります。

AXEONは、業務や課題を整理するだけで終わらず、必要な開発と導入まで対応するために設立しました。

## 削除する内容

- 少数精鋭
- 業界横断
- スタートアップの強み

`OUR STORY` などの英語補助ラベルも、UI上必須でなければ削除する。

# 5. 仕事で大切にしていること

## 見出し

仕事で大切にしていること

## 01｜実行方法まで具体化する

提案だけで終わらせず、必要な作業、担当、進め方まで整理します。  
実際に開発・導入できる内容かを確認してから進めます。

## 02｜導入後の使い方まで考える

誰が使い、誰が管理し、変更が必要なときにどう対応するかまで確認します。  
試作の確認だけでなく、実際の業務で使い続けられる状態まで考えます。

## 03｜関係者の認識をそろえる

経営側、現場、開発側で、目的や優先順位、制約の認識がずれないように確認します。  
専門用語に頼らず、判断に必要な内容を共有します。

`OUR PRINCIPLES` は、日本語見出しだけで成立する場合は削除する。
