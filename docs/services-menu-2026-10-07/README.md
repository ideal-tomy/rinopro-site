# スマホのSERVICE MENUを4枚の横スワイプカードに変更

プレビュー：http://127.0.0.1:3103/services

## 実装

- `ServicesMenu.tsx`：PC・スマホ共通の写真・タイトル・説明4枚。リンクなし。位置を示すドット4つはクリック・キーボードでも移動可能。自動送りなし。
- `ServicesPageContent.tsx`：従来のPC用メニューを共通部品に置き換え。
- `ServicesFlipCards.tsx`：重複するスマホの2枠を削除。180度回転の処理は変更せず、表示演出は外側のsectionに指定。
- `services-page.module.css`：スマホはカード80vw、左余白20px、間隔12px、写真16:10。CSS scroll-snapで左端に揃える。末尾のスクロール余白により4枚目も20px位置に揃う。PCの4列は維持（768～1023pxは従来の2列）。
- `ScrollRevealController.tsx`：既存の全ページ共通処理に明示的な対象・グループ・時間・遅延指定を追加。今回の対象は14px下から900ms、カード枠は125ms遅延。枠全体を初回だけ表示し、各カードには演出を付けない。回転は内側、表示演出は外側。「動きを減らす」設定は表示演出なし。未指定の既存対象は600msを維持。SSR属性の書き換えは行わない。

## 確認

320／375／390／430／768／1023／1024／1122／1280／1440pxで確認。全ページ横スクロールなし。カード4枚・リンクなし、80％幅・20px余白・12px間隔、次カードの一部表示、最終カード左端、ドット追従、矢印キー操作を検証した。Chromeのタッチ入力で横スワイプとスナップを確認。自動送りなし。表示演出は900ms／125ms、縦スクロールで戻っても再実行なし、動きを減らす設定では実行なし。コンソール・ページエラー0。詳細は [verification.json](verification.json)。PC・スマホのスクリーンショットも目視確認。

`npm run build`（TypeScript含む）、変更TSXのESLint、`git diff --check`が通過。

iPhone Safari実機は**未確認**。Windows Chromeのタッチ入力による確認と実機確認は区別する。本番反映・mainへのマージ・pushは行っていない。
