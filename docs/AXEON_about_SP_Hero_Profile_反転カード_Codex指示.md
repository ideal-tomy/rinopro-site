# Codex実装指示｜会社紹介ページ SP表示調整
## Hero・Profile・支援カードUI

対象:
- `/about`
- スマホ表示（主対象）
- PC表示は、今回明示した箇所以外は原則変更しない

目的:
- スマホ表示で情報のまとまりを分かりやすくする
- AI生成UIに見えやすい「細かいラベル分割」「アコーディオン乱用」を減らす
- 既存の「ご支援内容」ページで使っている反転カードUIを再利用し、サイト全体のUIルールを揃える
- 掲載内容そのものは変更せず、見せ方だけを整理する

---

# 0. 最重要ルール

今回の変更対象は主にスマホ表示です。

以下は勝手に変更しないでください。

- 代表あいさつ本文
- 各セクションの掲載内容
- 会社概要の内容
- PC表示の基本レイアウト
- サイト全体の配色
- ナビゲーション構成
- CTA文言
- 新しいセクションの追加

新しいUIをゼロから作るのではなく、
既に「ご支援内容」ページで実装済みのUI・挙動を確認し、再利用してください。

---

# 1. 実装前確認

コード変更前に必ず以下を確認してください。

1. `/about` のSP表示用CSS / responsive breakpoint
2. Hero見出しの定義元
3. Profileセクションのラベル・役職・氏名のDOM構造
4. 現在スマホでアコーディオン表示されている対象セクション
5. 「ご支援内容」ページの
   - コンサルティング
   - 半内製化（FED）
   の反転カード実装
6. PC / SPでカード挙動を切り替えている方法
7. hover / tap / scroll時の既存挙動
8. 共通カードcomponentとして再利用できるか

既存の反転カード実装が利用できる場合は、
同じ仕組みを優先してください。

今回のためだけに別のflip-card componentを乱立させないでください。

新しい営業コピーを追加しないでください。

---

## PC

今回の短いHero見出しはSP専用です。

## 具体ルール

### 残す

- `PROFILE`
- `代表`
- `秋吉 莉乃`
- 現在の代表あいさつ本文

### 統合する

`代表` と `秋吉 莉乃` を同じ見出し行 / 同じ見出しブロックにまとめる。

表示例:

```text
代表 秋吉 莉乃
```

---

## Strategy Lead

`Strategy Lead` が正式な表示として必要な場合は、
主見出しには入れず、小さな補助情報として扱ってください。

例:

```text
PROFILE

代表 秋吉 莉乃
Strategy Lead
```

ただし、

```text
PROFILE
代表
代表 / Strategy Lead
秋吉 莉乃
```

のような多段ラベルには戻さないでください。

# 11. SPカードの操作

既存の「コンサルティング / 半内製化（FED）」カードと同じ操作ルールを優先してください。

既存実装が、

- スクロール進入で一度演出
- 以降タップで表裏切替

などになっている場合は、
同じ挙動へ揃えてください。

新しい独自操作ルールを作らない。

---

# 12. スマホでhover前提にしない

SPではhoverを前提にしない。

必ずtapで操作できること。

表面 / 裏面が切り替わることを、
説明文を追加しなくても操作から理解できるUIにしてください。

必要なら、
既存カードと同じflip affordanceを使用してください。

---

# 13. カード表示幅

SPでは各カードを縦積みにする。

```text
[ 経営・業務の担当 ]

[ 開発・技術の担当 ]
```

左右余白:

```text
16〜20px程度
```

カード幅:

```text
width: 100%
```

カードの高さは、
表裏で極端に変化しないようにする。

可能なら同一min-heightを設定する。

---

# 14. カードデザイン

新しいデザインを作らず、
既存の「ご支援内容」ページのカードトーンに揃える。

共通させる項目:

- border-radius
- border
- shadow
- icon style
- flip transition
- front / back hierarchy
- tap response
- spacing

Aboutだけ別デザインにしない。

---

# 15. PC表示の支援体制

PCは現在の2カラム構造を原則維持してください。

今回の反転カード化はSPを主対象とします。

PCまで反転カードへ変更しない。

PCでは情報が一度に比較できる現在の構造を優先します。

---

# 16. 「仕事で大切にしていること」について

今回の実装では、
このセクションをアコーディオン化しないでください。

現在のSPでアコーディオンになっている場合は、
別途UI再設計予定のため、
今回勝手に「支援体制と同じflip card」に統一しない。

このセクションは会社の考え方を伝える場所なので、
サービスカードと同じ扱いにはしない。

---

# 17. アニメーション

既存のscroll revealを維持。

カードが表示される際は、
現在サイトで使用しているゆっくりしたfade / translateを使用する。

新しい派手なanimationは禁止。

flip animationは、
既存「コンサルティング / 半内製化（FED）」カードと同じ速度・easingへ揃える。

---

# 18. SPでの情報量

スマホでは、

「全部見せる」
ではなく、

「最初に概要 → 必要ならカードを反転して詳細を見る」

という構造にする。

ただし重要なセクション見出しまで隠さない。

---

# 19. 禁止事項

- 代表本文の変更

- 新しいコピー追加
- PC Heroの変更
