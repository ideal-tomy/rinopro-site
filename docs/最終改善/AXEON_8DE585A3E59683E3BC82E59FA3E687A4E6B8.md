## 0. ページの正しいサービス解釈

### 伝えるべきサービス

- AXEONが**外部のIT部門／外部のIT担当**となり、企業のITに関する相談、管理、改善を**契約で定めた範囲で継続して担当する**。
- 「専門知識のある人を社内で雇う」以外に、「外部の専門家と契約する」という選択肢を示す。
- 採用候補者の技術水準の見極めや育成、担当者一人への知識の集中、IT技術の変化、固定的な人件費への懸念を受け止める。
- AI、クラウド、セキュリティなどの新しい技術・サービスについても、**自社の業務に合うかを継続的に確認・検討できる**価値を示す。
- 契約する業務・対応時間・費用を明確にし、事業状況に合わせて契約内容の見直しを相談できるようにする。

### 言わないこと

- 「IT担当を雇えば解雇できない」「外注ならいつでも無条件で解約できる」などの断定。
- 「必ず採用より安い」「AXEONはどの社員より詳しい」「すべてのIT分野で常時最先端」「365日即時対応」など、根拠のない保証。
- 「半内製化＝お客様の社員をITエンジニアに育成すること」という説明への逆戻り。

本ページでは**社内の業務判断はお客様、専門的なIT対応はAXEON**という分担を明確にする。具体的な対応範囲と契約条件は個別に決める。

## 4. UI・デザイン再現ルール

- Hero：`linear-gradient(121deg, #F7FAFF 0%, #F7F9FC 57%, #EAF2FC 100%)`。
- 濃紺のAXEONパネル：`#133E79`。色の主役はHeroの「という選択。」と右側のAXEONパネル。
- 本文カラーは `#42516A` 前後の読みやすい濃色。薄いグレーだけで区別しない。
