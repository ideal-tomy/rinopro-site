# AI Prototype Factory — デモ制作候補リスト

> 業界特化型AIプロトタイプの制作候補・既存デモ・共同開発可能性を管理する台帳。
> 単なるAI機能紹介ではなく、業務フロー全体に踏み込み、
> 「この業界ではこういう応用ができる」という気づきを与えることを目的とする。

---

## ステータス定義

| 状態 | 意味 |
|------|------|
| 既存 | すでにデモあり |
| 改善中 | UIUX・機能・説明資料を強化中 |
| 制作予定 | 優先的に作る予定 |
| 候補 | アイデア段階 |
| 保留 | 一旦優先度を下げる |
| 共同開発検討 | 業界事業者との共同開発候補 |

---

## 優先度定義

| 優先度 | 判断基準 |
|--------|----------|
| A | 業界に強く刺さる、共同開発しやすい、他業界へも横展開可能 |
| B | 十分有望だが、Aより対象が限定的または競合が多い |
| C | 面白いが、現時点では優先度低め |

## 共同開発候補として重視する条件

- 業界事業者自身が販売者になれる
- 業界特有のノウハウが必要
- 汎用AIだけでは作りにくい
- 業務フロー全体に組み込める
- 継続利用される可能性がある
- 月額SaaSまたは導入支援型に発展できる
- 他社・他拠点へ横展開可能
