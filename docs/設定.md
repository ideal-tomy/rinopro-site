35. 最終確認時の判断基準
今回のゴールは、
「カードをきれいにした」
ではありません。
支援の進め方
どう進むのかが視線だけで分かる。
支援を始める前に
何を確認するのか選べることが分かる。
自社で進める際の課題
どんな課題に対し、
AXEONが何をするのかが1対1で分かる。
この3つが、
説明文を全部読まなくても
視覚的に理解できる状態を完成としてください。

今回かなり重要なのは、最後の **「3セクションを同じカードUIにしない」** です。

AIに普通に任せると、

**タイトル → 角丸カード → アイコン → 本文**

を3セクション全部に適用して、また「AIが作ったテンプレサイト」に戻りがちです。

今回の参考ビジュアルでは意図的に、

**進め方 = フロー**  
**始める前 = 選択UI**  
**課題 = 課題→回答**

とUIそのものを変えています。

ここまでCodexに固定しておくと、かなり再現しやすくなると思います。
