既存本文の「資料で終わらせず」は変更していない（見本の「資料で終わらず」と2文字分の差がある）。
既存フッターの体験デモリンクも維持しているため、SP見本の4リンクとは項目数が異なる。
ボタンは指定された最低44pxを優先しており、画像上のボタンより高い。元画像のフォント情報はないため、文字の輪郭・細かな折り返しが完全に同じとは限らない。
